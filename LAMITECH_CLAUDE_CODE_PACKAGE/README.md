# LAMITECH — pakiet dla Claude Code

## Jak uruchomić

1. Skopiuj cały folder do osobnego katalogu projektu.
2. Uruchom Claude Code z poziomu tego katalogu.
3. Upewnij się, że plik `CLAUDE.md` znajduje się w głównym katalogu.
4. Wklej zawartość `START_CLAUDE_CODE.txt` do Claude Code.
5. Zatwierdzaj wymagane operacje edycji plików i uruchamiania lokalnego serwera.

## Zawartość

- `CLAUDE.md` — nadrzędne wytyczne estetyczne,
- `01-research.md` — fakty i ograniczenia,
- `02-creative-directions.md` — kierunki oraz finalna idea,
- `03-brand-system.md` — system wizualny i typografia,
- `04-site-architecture.md` — mapa strony i sekcje,
- `05-content.md` — gotowe teksty,
- `06-image-prompts.md` — prompty do grafik w ChatGPT,
- `07-video-prompts.md` — prompty do wideo w Gemini,
- `08-claude-code-build-spec.md` — specyfikacja wykonawcza,
- `09-project-summary.md` — skrót projektu,
- `START_CLAUDE_CODE.txt` — tekst do wklejenia.

## Ważne

Materiały wizualne opisane w promptach są demonstracyjne. Nie mogą być przedstawiane jako prawdziwe realizacje LAMITECH. Fakty oznaczone w researchu jako wymagające potwierdzenia nie powinny być publikowane jako pewne informacje.
